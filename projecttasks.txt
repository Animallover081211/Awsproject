Here are the **actual questions/tasks** in your coursework (simplified so you can clearly see what you need to answer/do):

---

## ✅ **Task 1: Resource Creation (20 marks)**

1. Create an **EC2 instance using Boto3 (Python)**.
2. Create a **DynamoDB table using Boto3** (single primary key = image name).
3. Create:

   * **SQS queue**
   * **S3 bucket**
     using a **CloudFormation template (parameterised)**.

---

## ✅ **Task 2: Image Upload & Trigger (20 marks)**

1. Describe:

   * EC2 configuration
   * Software installed
   * How images are copied to EC2

2. Upload images:

   * From EC2 → S3
   * Using Python (Boto3)
   * One image every **30 seconds**

3. Explain setup where:

   * Upload → sends message to **SQS**
   * SQS → triggers a **Lambda function**

---

## ✅ **Task 3: Face & Label Detection (20 marks)**

1. Create a **Lambda function** to read data from SQS messages.

2. Use **AWS Rekognition** to:

   * Detect labels (e.g., driving)
   * Detect faces (emotions)

3. Explain:

   * How Lambda accesses AWS services

4. Create:

   * **SNS topic**
   * Email notification setup

---

## ✅ **Task 4: Database & Notification (20 marks)**

1. Extract results from Rekognition:

   * Driving detection
   * Emotions

2. Store in DynamoDB:

   * Only emotions: **ANGRY** and **DISGUSTED**
   * Include confidence values

3. Trigger **second Lambda function** when DB updates.

4. Send email **ONLY IF**:

   * Person is driving
   * AND emotion = angry
   * AND confidence > 80%

---

## ✅ **Task 5: Report, Analysis & Evaluation (20 marks)**

1. Explain your solution + evaluate the architecture (Figure 1)

   * Suggest improvements

2. Explain how to build this on:

   * **Google Cloud OR Microsoft Azure**

3. Security analysis:

   * How to secure the system in AWS

4. Cost optimisation:

   * How to reduce cost for long-term usage

---

## ⚠️ Important: What you’re actually submitting

* A **Word report (.docx)**
* Must include:

  * Code (Python, CloudFormation, policies)
  * Screenshots
  * Explanations for each task

---

## 💡 In short (what examiners want)

They are testing if you can:

* Build a **full AWS pipeline**
* Use **Boto3 + Lambda + Rekognition**
* Connect services (**S3 → SQS → Lambda → DynamoDB → SNS**)
* And **explain + evaluate** everything
